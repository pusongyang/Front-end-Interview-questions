# AI Coding 面试任务（1 小时 / 考察 Harness AI）

这套材料用来评估实习生**驾驭 AI 写代码的能力**（Harness AI），而不是算法刷题，也不是「会不会从零搭一个站」。

候选人可以使用 Cursor、Claude、Copilot 或任何 AI 工具。面试官看的是：**怎么拆任务、怎么给 AI 上下文、怎么验证、AI 错了怎么纠偏**。

## 60 分钟怎么用

1. **0–5 分钟**：确认工具可用（Cursor / 浏览器 / Node），说明「必须用 AI，但你对结果负责」。
2. **5–50 分钟**：做题，屏幕共享，鼓励出声思考。
3. **50–60 分钟**：复盘——AI 帮了什么、你改了什么、还缺什么、如果再有 30 分钟做什么。

期望完成：**P0 全过 + P1 至少做出 labels 或 URL 筛选之一**。P2 是加分项。
