# 面试任务：迷你 Issue Board（60 分钟）

可以使用 Cursor、ChatGPT、Claude、Copilot 等任何 AI 工具。你对提交的代码负责。请出声思考：你打算先做什么、为什么这么问 AI、你怎么验证它说得对。

## 背景

本目录下的 `starter/` 是一个不依赖构建工具的 Issue 列表。逻辑在 `core.js`，页面在 `index.html` + `ui.js`。用本地 `localStorage` 存数据。

```bash
cd starter
npm test          # Node 18+ 即可，无第三方依赖
# 用浏览器直接打开 starter/index.html 也可手动点
```

请尽量**保持现有导出函数名**（测试在用）。不要引入 React/Vue/打包器。

## P0（先做完这些）

1. **搜索**：输入应忽略大小写，并同时匹配 `title` 和 `body`。空搜索 = 显示当前筛选下的全部。
2. **状态筛选**：`open` / `done` / `all`。选 `all` 时应看到所有状态。
3. **XSS**：标题或正文里的 HTML / 脚本不得当作页面来执行。请自己构造危险输入验证。

## P1

4. **Labels**：创建 Issue 时可填写 labels（逗号分隔，去空格、忽略空项）。列表可按某一个 label 筛选。
5. **筛选可叠加**，并且当前筛选（搜索词、状态、label）要能反映在 **URL query** 里，刷新或把链接发给别人应恢复同样的视图。

「可叠加」的具体语义请你自己选定并写在 `starter/DECISIONS.md`（三四句话即可）。面试官可能问你为什么这么选。

## P2（有时间再做）

6. 不允许空标题（提交时应被拒绝，已有数据不受影响）。
7. 删除一条 Issue 后再创建，**不得复用**被删 id。
8. 为你改过的行为补测试。

## 结束时请准备说

- 实际做完了哪些验收项。
- 哪一段是 AI 写的、你改过什么、还剩什么。
- 如果再给你 30 分钟，下一步是什么。
